# Archive manifest

Archived code is retained for traceability and is not part of supported builds.

- `atlas/`: retired Atlas/PBS runners, adaptive scheduler experiments,
  historical monitor adapters, tests, and server notes.
- `campaigns/`: one-city or one-campaign launchers, recovery scripts, plots,
  probes, and design snapshots.
- `legacy-apps/`: superseded web scraper, change monitor, time-series pipeline,
  and earlier macOS monitor implementations.

Do not restore an archived component to the active tree without reviewing its
credentials, paths, dependencies, and data-format assumptions.
