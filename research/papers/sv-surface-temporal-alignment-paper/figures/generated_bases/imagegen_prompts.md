# Image Generation Prompts for Structural Figures

Generated base images are used only for conceptual/structural manuscript
figures. All scientific labels, formulas, table names and numeric counts are
overlaid programmatically by `scripts/build_paper_figures.py`.

## `fig_01_conceptual_pipeline_base.png`

Use case: scientific-educational

Asset type: manuscript figure background for a peer-reviewed urban analytics paper

Primary request: Create a clean, high-end scientific schematic background for a workflow that turns Google Street View panorama pixels into world-space surface factors and then temporal surface atlases. No text, no labels, no numbers, no logos, no watermark.

Composition: widescreen 16:9. Left to right sequence with six visual stages: spherical panorama strip, pixel ray bundle, translucent planar patch, local-to-world coordinate triad, merged facade surface factor, and time-series surface grid. Use thin vector-like lines, muted scientific colors, white background, precise geometry, subtle depth, elegant Nature/Science-style graphical abstract aesthetic.

Important constraints: absolutely no readable text, no pseudo-text, no equations, no icons with letters. Leave generous white space around elements so exact labels can be overlaid later.

## `fig_02_data_acquisition_base.png`

Use case: scientific-educational

Asset type: manuscript figure background for data acquisition section

Primary request: Create a clean scientific schematic background for one-time evidence acquisition in a Google Street View geometry study. No text, no labels, no numbers, no logos, no watermark.

Composition: widescreen 16:9. Two large source streams on the left: spatial street-view capture and temporal historical capture. The streams flow into a central raw evidence archive, then into a right-side structured database/catalog. Show recognizable but generic visual motifs: panorama tile mosaic, photometa binary packet, parsed JSON document shape, timeline strip, small point-cloud cube, POI nodes, and catalog table cards. Use thin lines, muted blue/green/amber colors, white background, precise minimal scientific illustration style, journal-quality figure design.

Important constraints: absolutely no readable text or pseudo-text, no equations, no letters. Leave generous white space for exact labels and counts to be overlaid later.

## `fig_06_catalog_schema_base.png`

Use case: scientific-educational

Asset type: manuscript figure background for database/catalog schema

Primary request: Create a clean high-end scientific database schema schematic for a Street View surface-temporal alignment catalog. No text, no labels, no numbers, no logos, no watermark.

Composition: widescreen 16:9, white background. Show grouped table modules connected by thin arrows: raw evidence group, parsed geometry group, factor geometry group, visibility/quality group, surface texture group, temporal correspondence group. Use abstract table cards without readable text, small row/column lines, colored group boundaries, and file icons for raster assets outside the database. The layout should look like a polished ERD figure in a computational urban science paper, not a business slide. Use muted navy, teal, amber, green, rose accents, thin lines, restrained shadows, precise alignment.

Important constraints: no readable text or pseudo-text anywhere; leave space for exact table names and row counts to be overlaid programmatically.
